Floating & Fixed Position elements

CSS "Float"

Block elements can be positioned alongside each other using the CSS property float: left or right. The clear property can also be used, set as left|right|both. Float is only supported on block elements.
A block element next to a float has the padding adjusted so that content fits in the remaining width.
