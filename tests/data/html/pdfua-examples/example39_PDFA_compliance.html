PDFA Compliance

PDF/A1-b is a file format for the long-term archiving of electronic documents. This is an example of a PDF/A1-b compliant file combined with PDF/UA-1 accessibility requirements.

When both PDFA and PDFUA are enabled, the resulting document must conform to both standards simultaneously. The XMP metadata stream must declare conformance to both ISO standards.

Key requirements for PDF/A + PDF/UA coexistence

  • All fonts must be embedded (required by both standards)
  • No encryption permitted (PDF/A requirement)
  • MarkInfo dictionary required (PDF/UA requirement)
  • StructTreeRoot required (PDF/UA requirement)
  • XMP metadata must declare both conformance levels
