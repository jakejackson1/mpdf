Backgrounds and Borders

Page background

The background colour can be set by CSS styles on the body tag. This will set the background for the whole page. In this document, the background has been set as a gradient.

Background Gradients

Background can be set as a linear or radial gradient between two colours. The background has been set on this div element to a linear gradient.
The background has been set on this div element to a radial gradient. (x1, y1, x2, y2, r) where (x1, y1) is the starting point with color1, (x2, y2) is the centre with color2, and r is the radius.

Rounded Borders

Rounded corners to borders can be added using border-radius as defined in the draft spec of CSS3. The two length values of the border-*-radius properties define the radii of a quarter ellipse that defines the shape of the corner of the outer border edge.
border-radius: 4em; would be equivalent to border-top-left-radius: 4em; border-top-right-radius: 4em; border-bottom-right-radius: 4em; border-bottom-left-radius: 4em.
